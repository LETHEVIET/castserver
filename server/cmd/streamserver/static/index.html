Quick Start

1. Stream a video file

./streamserver -source file:///path/to/video.mp4

Then on the 3DS just connect — it will use the server default.

2. Stream from mpv (with playback control)

mkfifo /tmp/mpvstream
mpv video.mp4 --o=/tmp/mpvstream --of=mpegts --ovc=libx264 --oac=aac &
./streamserver -source file:///tmp/mpvstream

3. Stream your screen (Linux)

ffmpeg -f x11grab -i :0.0 -vf "scale=256:192" -c:v libx264 -f mpegts /tmp/screen.ts &
./streamserver -source file:///tmp/screen.ts

4. Stream from VLC

# In VLC: Media → Stream → HTTP, port 8080, path /stream
./streamserver -source http://localhost:8080/stream
